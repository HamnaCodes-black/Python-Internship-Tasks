# Python-Internship-Tasks

This repository contains the Python projects completed during my internship.

## Projects

### 1. Hangman Game
A simple command-line Hangman game developed using Python.

Features:
- Random word selection
- Letter guessing
- Incorrect guess tracking
- Hangman drawing
- Win and loss conditions

### 2. Stock Portfolio Tracker
A Python program that calculates the total investment based on stock prices and quantities entered by the user.

Features:
- Predefined stock prices
- Stock and quantity input
- Investment calculation
- Input validation
- Total portfolio value calculation
- Saves the result to a text file

### 3. Basic Rule-Based Chatbot
A simple rule-based chatbot that responds to predefined user inputs.

Features:
- User input handling
- Predefined responses
- If-elif conditions
- Functions
- Continuous conversation loop
- Exit option

## Technologies Used

- Conditional Statements
